# opencode-sessions-all

TUI plugin for OpenCode v2 that shows ALL sessions from ALL projects in the left sidebar, grouped by project (collapsible), with a "+ New" chat button.

Dev install: `ln -sfn /home/sattorov/opencode-sessions-all ~/.config/opencode/plugins/opencode-sessions-all`

Build: `npm install && npm run build` (bundles src/tui.tsx → dist/tui.js)

Uninstall: `rm ~/.config/opencode/plugins/opencode-sessions-all`
